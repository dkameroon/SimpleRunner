# 🏃 Simple Runner

## 📌 Project Overview

SimpleRunner is an exciting endless runner where the player controls a character running forward. The goal is to jump over obstacles, avoid traps, and collect gold coins. As the game progresses, the speed increases, challenging the player’s reaction and agility.

## 🎮 Implemented Features

### 🏗 Core Systems
- ✅ **Character Control** - Allows the player to jump and navigate obstacles.
- ✅ **Collision System** - Detects interactions with traps, obstacles, and coins.
- ✅ **Difficulty Progression** - Gradually increases speed to enhance challenge.
- ✅ **Procedural Generation** - Randomly spawns obstacles for a dynamic experience.
- ✅ **UI System** - Displays collected coins, current score, and high score.

## 🛠 Detailed Breakdown

### 🏃 Character Movement
- The character runs automatically and jumps with a simple tap.
- Jump height is fixed for easy and responsive controls.
- Physics-based movement ensures smooth animations.

### 🚧 Obstacle and Trap System
- Randomized obstacle placement for varied gameplay.
- Collision system detects hits with obstacles and coins.
- Different types of traps increase game difficulty.

### 💰 Coin Collection and Score System
- Players collect coins to increase their score.
- High score is saved and displayed in the UI.
- Score tracking adapts to difficulty progression.

### 📈 Difficulty Scaling
- The game starts at a moderate speed and gradually increases difficulty.
- Speed scaling is balanced to provide a fair challenge.
- Players must react quickly to avoid obstacles.

### 💾 Save System
- High scores are saved using PlayerPrefs.
- Automatically loads previous high score on game start.

### 🎨 UI/UX Design
- Minimalist interface displaying current score, high score, and collected coins.
- Tap control for intuitive character movement.

## 🔧 Technologies Used
- **Unity 2022.3.0f1** (LTS version for stability)
- **C#** for game logic and mechanics
- **Asset Store Tools** for animation optimization and obstacle prefabs
- **Unity Physics** for movement and collision detection

## 📲 Platforms
- Available exclusively for **Android**

## 🏆 Conclusion
SimpleRunner is a well-optimized and engaging endless runner that provides a dynamic challenge for players. The procedural obstacle generation, increasing difficulty, and intuitive controls make it an exciting experience. 🚀

- ✅ **Прогресія складності** - Поступово збільшує швидкість для підвищення рівня виклику.
- ✅ **Процедурна генерація** - Випадковим чином створює перешкоди для динамічного ігрового процесу.
- ✅ **UI система** - Відображає зібрані монети, поточний рахунок і найкращий результат.

# 🏃 Simple Runner

## 📌 Обзор проекта

Simple Runner — это захватывающий бесконечный раннер, в котором игрок управляет персонажем, бегущим вперёд. Цель — перепрыгивать препятствия, избегать ловушек и собирать золотые монеты. По мере продвижения скорость увеличивается, испытывая реакцию и ловкость игрока.

## 🎮 Реализованные функции

### 🏗 Основные системы
- ✅ **Управление персонажем** - Позволяет игроку прыгать и обходить препятствия.
- ✅ **Система столкновений** - Обнаруживает взаимодействия с ловушками, препятствиями и монетами.
- ✅ **Прогрессия сложности** - Постепенно увеличивает скорость для повышения вызова.
- ✅ **Процедурная генерация** - Случайное появление препятствий для динамичного игрового опыта.
- ✅ **Система UI** - Отображает собранные монеты, текущий и рекордный счёт.

## 🛠 Подробное описание

### 🏃 Движение персонажа
- Персонаж бежит автоматически и прыгает по касанию экрана.
- Высота прыжка фиксирована для удобного и отзывчивого управления.
- Физически обоснованное движение обеспечивает плавные анимации.

### 🚧 Система препятствий и ловушек
- Случайное размещение препятствий для разнообразного игрового процесса.
- Система столкновений обнаруживает попадания с препятствиями и монетами.
- Различные типы ловушек увеличивают сложность игры.

### 💰 Система сбора монет и очков
- Игроки собирают монеты, увеличивая свой счёт.
- Рекордный счёт сохраняется и отображается в UI.
- Отслеживание очков адаптируется к прогрессии сложности.

### 📈 Масштабирование сложности
- Игра начинается с умеренной скорости и постепенно усложняется.
- Балансировка скорости обеспечивает честный вызов.
- Игроки должны быстро реагировать, чтобы избегать препятствий.

### 💾 Система сохранений
- Рекордные очки сохраняются с использованием PlayerPrefs.
- Автоматическая загрузка предыдущего рекорда при запуске игры.

### 🎨 UI/UX Дизайн
- Минималистичный интерфейс, отображающий текущий счёт, рекорд и собранные монеты.
- Управление касанием для интуитивного взаимодействия.

## 🔧 Используемые технологии
- **Unity 2022.3.37f1** (LTS-версия для стабильности)
- **C#** для игровой логики и механик
- **Инструменты из Unity Asset Store** для оптимизации анимации и префабов препятствий
- **Физика Unity** для движения и обнаружения столкновений

## 📲 Платформы
- Доступно эксклюзивно для **Android**

## 🏆 Заключение
Simple Runner — это хорошо оптимизированный и увлекательный бесконечный раннер, который обеспечивает динамичный вызов для игроков. Процедурная генерация препятствий, растущая сложность и интуитивное управление делают его захватывающим игровым опытом. 🚀
